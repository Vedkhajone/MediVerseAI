## 📖 Overview

MediVerse AI is a modern full-stack healthcare platform designed to assist patients, doctors, and healthcare administrators by integrating intelligent medical management with AI-powered clinical decision support.

The platform aims to digitize healthcare workflows while incorporating machine learning models for disease prediction, medical image analysis, and intelligent healthcare assistance.

Rather than being a standalone prediction model, MediVerse AI combines multiple healthcare applications into one scalable ecosystem.

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/MediVerseAI.git
```

---

## Frontend

```bash
cd frontend

npm install

npm run dev
```

---

## Backend

```bash
cd backend

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

python -m uvicorn app.main:app --reload
```
